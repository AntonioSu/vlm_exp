逐项简介

每个基座构件在做什么

  • Linear Attention

    GDN

    Gated DeltaNet

    把「注意力」改成对固定维状态矩阵的递推更新：用 delta rule 做可纠错写入，用 exponential gating（通常 head-wise / 标量）控制遗忘；前面常接 causal Conv1D。相对 softmax，长序列更省内存与算力。

    核心：固定状态 S · 粗门控 · 本轮 Qwen3.5 主路径

  • Linear Attention+

    KDA

    Kimi Delta Attention

    Moonshot Kimi Linear 的核心算子：在 GDN 骨架上把标量/头级衰减换成对角通道门控 Diag(α_t)，每个特征维独立决定记多久。配合专用 DPLR chunkwise 并行，更吃 Tensor Core，也更利于混合架构里的 RNN 式记忆控制。

    核心：GDN + channel-wise gate · 更细的遗忘控制 · 本轮未用

  • Update Rule

    Delta Rule

    Error-correcting write

    状态更新不是简单累加，而是按「当前键上的误差」做修正写入。GDN / KDA 都建立在这条规则上；差别主要在遗忘门有多细，而不是要不要 delta。

    核心：selective overwrite · GDN 与 KDA 共用

  • Softmax / MLA

    Full Attention

    精确检索层

    经典 QKᵀV + softmax（Qwen 侧常配 GQA + RoPE），或 Kimi 侧的 Full MLA。负责补齐纯线性注意力在精确拷贝 / 长程指针上的短板；Hybrid 里按固定间隔出现。

    核心：完整 KV / 压缩潜变量 · O(L²) 或 MLA 变体 · 周期插入

  • Architecture

    Hybrid

    Linear ×3 + Full ×1

    整网约 75% 线性层 + 25% 精确层。本实验：GDN ×3 + Full ×1（Qwen3.5）。对照谱系：Kimi Linear 为 KDA ×3 + MLA ×1。配方同构，换的是线性算子。

    核心：效率层堆叠 + 周期精确层 · 本轮用 GDN 版

  • Scale note

    MoE

    Sparse experts（大规格）

    更大规格 Qwen3.5 还会叠 Sparse MoE。本看板主实验 2B / 4B 是 dense + GDN Hybrid，无专家路由变量。

    本轮：dense Hybrid · 无 MoE
