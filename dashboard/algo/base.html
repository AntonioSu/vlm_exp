Linear Attention · 本轮底座

GDN

Gated DeltaNet

把「注意力」改成对固定维状态矩阵的递推更新：用 delta rule 做可纠错写入，用 exponential gating（通常 head-wise / 标量）控制遗忘；前面常接 causal Conv1D。相对 softmax，长序列更省内存与算力。本轮 Qwen3.5 的主路径算子。

核心：固定状态 S · 粗门控 · 近线性复杂度 · 本轮 2B/4B 主路径

优点

固定大小状态，长序列内存近似常数；算力近线性，适合长 response / 长上下文训练；delta + gate 比朴素累加更可控；生态与 Qwen3.5 / FLA·Triton 核成熟。

缺点

遗忘门偏粗（头级/标量），细粒度记忆控制弱于 KDA；精确拷贝 / 长程指针弱于 Full Attn，通常要 Hybrid 补齐；依赖专用核，换栈成本高于标准 FlashAttention。

Linear Attention+ · 谱系对照

KDA

Kimi Delta Attention

Moonshot Kimi Linear 的核心算子：在 GDN 骨架上把标量/头级衰减换成对角通道门控 Diag(α_t)，每个特征维独立决定记多久。配合专用 DPLR chunkwise 并行，更吃 Tensor Core。本轮未使用，仅作粗门控 vs 细门控对照。

核心：GDN + channel-wise gate · 更细遗忘控制 · 本轮未用

优点

通道级遗忘，记忆节奏比 GDN 更细；仍守 delta rule，表达力与可控性通常更强；DPLR 实现利于混合架构里的 RNN 式记忆；与 MLA Hybrid 配方在 Kimi Linear 上已验证。

缺点

实现与核更复杂，工程栈不如 GDN 在 Qwen 侧现成；门控参数更多，训练/调试面更大；本轮底座是 Qwen3.5 GDN，换 KDA 等于换模型族，无法作「只改 RL」对照。

Update Rule

Delta Rule

Error-correcting write

状态更新不是简单累加，而是按「当前键上的误差」做修正写入。GDN / KDA 都建立在这条规则上；差别主要在遗忘门有多细，而不是要不要 delta。

核心：selective overwrite · GDN 与 KDA 共用

优点

可纠错写入，减轻状态被无关信息永久污染；比纯累加线性注意力更稳、更可解释；为门控遗忘提供清晰的「写 / 改 / 忘」分工。

缺点

单独不足以解决长程精确检索；实现依赖 chunkwise / 递推数值稳定；与 softmax Full Attn 的机制不同，调试直觉不能直接迁移。

Softmax / MLA · 精确层

Full Attention

精确检索层

经典 QKᵀV + softmax（Qwen 侧常配 GQA + RoPE），或 Kimi 侧的 Full MLA。负责补齐纯线性注意力在精确拷贝 / 长程指针上的短板；Hybrid 里按固定间隔出现。Softmax 归一化也是 Attention Sink 出现的温床。

核心：完整 KV / 压缩潜变量 · O(L²) 或 MLA 变体 · 周期插入

优点

精确长程检索与拷贝能力强；生态成熟（FlashAttention 等）；Hybrid 里少量插入即可显著补齐线性层短板。

缺点

算力/显存随长度近似平方（或 MLA 仍有增长的 KV）；易出现 Attention Sink / massive activation；全网若全用 Full，长序列成本远高于 GDN 主路径。

Phenomenon · Softmax 侧效应

Attention Sink

注意力汇 · StreamingLLM

Softmax 强制注意力权重和为 1：许多 token 并不「该」被关注时，模型仍要把概率质量倒到某处——全局可见的序列首部 token就常成为汇点，即使语义不重要。StreamingLLM 据此做流式推理：滑窗 KV 之外始终保留若干 sink token 的 KV，避免窗口滑走后 perplexity 尖峰。门控 / 线性注意力路径往往能削弱这一现象。本轮非训练变量。

核心：首部汇聚 · 流式留 sink KV · 主要见于 Full Attn

优点

利用汇点可做稳定流式：滑窗 + 少量 sink KV，无需重训即可撑很长上下文；实现相对轻量；解释了为何「丢掉首 token」会突然崩质量。

缺点

本质是 softmax 侧效应，会扭曲注意力分布、伴随 massive activation；滑窗仍丢中间语义；需改 KV 管理（与 prefix cache / CUDA graph 等可能冲突）；门控模型上现象减弱，策略收益也变小。

Architecture · 本轮布局

Hybrid

Linear ×3 + Full ×1

整网约 75% 线性层 + 25% 精确层。本实验：GDN ×3 + Full ×1（Qwen3.5，full_attention_interval=4）。对照谱系：Kimi Linear 为 KDA ×3 + MLA ×1。配方同构，换的是线性算子。

核心：效率层堆叠 + 周期精确层 · 本轮用 GDN 版

优点

兼顾效率与检索：多数层近线性，少数层补精确能力；比纯 Full 更省长上下文成本；比纯线性更不易在拷贝/指针任务上翻车；工业界（Qwen / Kimi）已验证可行。

缺点

异构算子栈（GDN 核 + FlashAttention）更难运维；间隔超参（3:1 等）需经验；Full 层仍带 sink / KV 增长；调试时要分清瓶颈在线性态还是精确层。

Scale note · 大规格

MoE

Sparse experts

更大规格 Qwen3.5 还会叠 Sparse MoE。本看板主实验 2B / 4B 是 dense + GDN Hybrid，无专家路由变量。

本轮：dense Hybrid · 无 MoE

优点

同等激活参数下可放大总容量；大规格训练/推理性价比高；与 Hybrid 注意力正交，可叠加。

缺点

路由不稳、负载不均；通信与实现复杂；小规格（2B/4B）收益有限，本轮刻意不用以免混淆 RL 变量。
