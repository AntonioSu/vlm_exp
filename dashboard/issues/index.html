读实验数字时先排除这几件事
  1. 先确认奖励键是 reward.*，第一步 reward 不该钉在 −1。
  2. 不要把 v1 E2 当成带 Dynamic Sampling 的 DAPO；那一键从未生效。
  3. shaped overlong 之后 pass 看 critic/score/mean，不要用含惩罚的 critic/rewards/mean。
  4. 算法排名以 math_500 为准；AIME 30 题噪声太大，4B 五组差会落在 ±8pt 里。
