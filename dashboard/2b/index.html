概览

E1 GRPO · 一页速览

E1 · GRPO baseline —— 保留 low_var_kl 形式 KL loss 的 GRPO 组

组内均值 baseline + 除以组内 std；KL loss 系数 1e-3。pass 由首步 ~43% 升到末段 60%+；entropy 平稳收敛。

  • 算法设定：组相对 advantage（均值÷std）；KL loss=1e-3。
  • 学习信号：pass ~43%→~63%；entropy 0.45→0.19；响应长度中等。
  • 稳定性：有 KL 拉住；rollout↔训练一致性良好。
  • 耗时：均值 ~10.4 min/step；总墙钟 26h21m。
  • 评测：offline mmlu@150=80.0%；aime25@150=30.4%；训练验证 aime24@150=33.3%。

概览

E2 DAPO · 一页速览

E2 · DAPO —— 响应最短、墙钟最快（21h12m）

Clip-Higher + Dynamic Sampling + Overlong Reward Shaping；关闭 KL loss。长度压得最狠，但本数据下 pass / AIME 未换来优势。

  • 算法设定：DAPO 三件套；关闭 KL（无 ref）。
  • 学习信号：长度下降最快最深；entropy 全程偏高且末段仍走松。
  • 稳定性：无 KL；更新更激进，早期 pass 更不稳。
  • 耗时：均值 ~8.4 min/step；总墙钟 21h11m（五组最快）。
  • 评测：offline mmlu@150=80.2%；aime25@150=30.0%。

概览

E3 Dr.GRPO · 一页速览

E3 · Dr.GRPO —— 熵最紧、后段 pass 最高，长度涨幅最大

不除组内 std + seq-mean-token-sum-norm；关闭 KL。2B 上长度涨得最多（与 4B 结论相反）。

  • 算法设定：Dr.GRPO；关闭 KL。
  • 学习信号：entropy 收得最紧；末段 pass 均值五组最高带；长度不降反升。
  • 稳定性：grad 基线最低；step133–140 有瞬时尖峰。
  • 耗时：均值 ~10.4 min/step；总墙钟 26h11m。
  • 评测：offline mmlu@150=80.6%；aime25@150=35.0%（第二）；训练 aime24@150=40%。

E4 RLOO · 一页速览

E4 · RLOO —— 起步最快，offline aime25@150 最高（37.5%）

留一法 baseline，保留 KL loss。起步 pass 最高；墙钟略慢（多一次 ref）。

  • 算法设定：RLOO leave-one-out；KL loss=1e-3。
  • 学习信号：起步最快；末段稳定在 63–67%；长度居中。
  • 稳定性：有 KL；与 E1 收敛节奏接近。
  • 耗时：均值 ~10.6 min/step；总墙钟 26h48m（略慢）。
  • 评测：offline aime25@150=37.5%（五组最高）；mmlu@150=78.6%。

E5 REINFORCE++ · 一页速览

E5 · REINFORCE++ —— offline mmlu@150 最高（81.9%）

全 batch 白化折扣 return + mse 形式 KL loss。mmlu 末点五组最高；aime25 末点第二。

  • 算法设定：REINFORCE++；mse KL loss。
  • 学习信号：pass 末段与 E1/E4 同带；entropy 收敛偏紧。
  • 稳定性：有 KL；后期 grad 偶有抬升。
  • 耗时：均值 ~10.2 min/step；总墙钟 25h41m。
  • 评测：offline mmlu@150=81.93%（最高）；aime25@150=36.7%。
