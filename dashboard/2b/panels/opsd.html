概览

OPSD 2B←2B · easy × 24K · 一页速览

OPSD · On-Policy Self-Distillation —— 2B student ← 冻结 2B teacher

与 OPD 同数据同 24K、同一套 k1 distill；教师换成学生自己的冻结 2B init。对照：Easy-24K DAPO（点线）+ OPD 2B←4B（金色短点）。

  • 算法设定：k1 + policy gradient · 关 task reward · 关 KL/ref。脚本 experiments_opd_distill/run_opsd_easy_24k_2b.sh。
  • 训练：500/500 · ~61.90h · rollout acc 均值 41.0%。
  • offline / agent：offline 报告已开始写入，agent 尚未评测。sync_2b_eval_dashboard.py / sync_2b_agent_dashboard.py 会自动叠 EVAL_FULL_OPSD / AGENT_OPSD。

展开 stage 释义 · gen / update_actor / ref / adv …
  • gen (rollout)：vLLM 采样生成响应，通常占一半以上时间；随响应变长而抬升。
  • update_actor：FSDP 上策略网络反向与参数更新（PPO/GRPO clip 目标）。
  • ref：参考模型前向算 logprob，供 KL loss；关闭 KL 的组此项为 null/≈0。
  • old_log_prob：用更新前策略再算一遍 logprob，供重要性采样 ratio。
  • update_weights：把新权重同步回 rollout engine（vLLM），一般数秒。
  • adv：advantage 计算阶段墙钟（含 reward 整理 + compute_advantage），不是 advantage 数值本身；通常 <1s。
  • reward：打分/奖励函数本身的计时；多数配置下几乎可忽略（≈0）。
