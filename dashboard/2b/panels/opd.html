概览

OPD 2B←4B · easy × 24K · 一页速览

OPD · On-Policy Distillation —— 2B student ← 冻结 4B teacher

学生自己采样，冻结 4B 教师在整段轨迹上给 top-k。同数据同 24K 窗口对照 Easy-24K DAPO；OPSD 把教师换成 2B 自己的冻结 init。

  • 算法设定：k1 + policy gradient · 关 task reward · 关 KL/ref。脚本 experiments_opd_distill/run_opd_easy_24k_2b.sh。
  • 训练：500/500 · ~39.13h · rollout acc 均值 52.2%。
  • offline：mmlu / aime24 / aime25 / MATH-500 均 50/50。峰值 mmlu @450 = 79.90%；MATH-500 @350 = 81.62%。
  • agent：BFCL 50/50（峰值 @210 = 53.6%）；tau 50/50（峰值 @420 = 60.0%）。

展开 stage 释义 · gen / update_actor / ref / adv …
  • gen (rollout)：vLLM 采样生成响应，通常占一半以上时间；随响应变长而抬升。
  • update_actor：FSDP 上策略网络反向与参数更新（PPO/GRPO clip 目标）。
  • ref：参考模型前向算 logprob，供 KL loss；关闭 KL 的组此项为 null/≈0。
  • old_log_prob：用更新前策略再算一遍 logprob，供重要性采样 ratio。
  • update_weights：把新权重同步回 rollout engine（vLLM），一般数秒。
  • adv：advantage 计算阶段墙钟（含 reward 整理 + compute_advantage），不是 advantage 数值本身；通常 <1s。
  • reward：打分/奖励函数本身的计时；多数配置下几乎可忽略（≈0）。
