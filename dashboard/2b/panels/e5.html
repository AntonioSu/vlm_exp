展开 stage 释义 · gen / update_actor / ref / adv …
  • gen (rollout)：vLLM 采样生成响应，通常占一半以上时间；随响应变长而抬升。
  • update_actor：FSDP 上策略网络反向与参数更新（PPO/GRPO clip 目标）。
  • ref：参考模型前向算 logprob，供 KL loss；关闭 KL 的组此项为 null/≈0。
  • old_log_prob：用更新前策略再算一遍 logprob，供重要性采样 ratio。
  • update_weights：把新权重同步回 rollout engine（vLLM），一般数秒。
  • adv：advantage 计算阶段墙钟（含 reward 整理 + compute_advantage），不是 advantage 数值本身；通常 <1s。
  • reward：打分/奖励函数本身的计时；多数配置下几乎可忽略（≈0）。
