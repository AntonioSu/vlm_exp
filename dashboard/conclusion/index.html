一句话总览

四轴交叉：规模会改写算法排序；共享超参固定后主要差在 KL / 归一化 / 长度机制；多模态只动图文占比；数学 RL 几乎不抬 agent

没有「全能冠军」——按目标选轴，再选算法
Size：2B 算法排序更散；4B 训练 pass 挤一团，必须看 offline。 Param：有 KL 更稳、关 KL 更快也更极端；DAPO 的 overlong 是长度主开关。 MM：固定 GRPO + 2B，只改图文占比；M0 formal 文本强、Geo3K 已有基线；纯图文 M1 light 文本崩得很快。 Algo：吞吐看 DAPO；2B 定盘数学看 RLOO；通识峰值看 Dr.GRPO / REINFORCE++。

Size

2B 敏感 · 4B 评测拉开

规模放大后 train-pass 区分度下降；DAPO 数学从 2B 弱势 → 4B 峰值。

Param

KL / 长度机制决定风险面

共享 lr / batch / n / 16K；差异集中在 KL、std 归一化、Clip-Higher、Overlong。

MM

配比是唯一自变量

M0=E1 文本端点；M1 100% 图文换视觉但文本 light 崩；M2/M3 formal 评测待补。

Algo

目标不同，赢家不同

E2 最快；E4 定盘 2B 数学；E3/E5 通识；E1 作稳健锚点。

1 · Model Size（2B vs 4B）

同一套 E1–E5 算法定义，只改底座规模 —— 哪些结论跨规模成立、哪些反转

两边成立

DAPO 永远最快、长度最短

无 ref 前向 + overlong shaping：2B 墙钟 ~21h、4B ~32.6h，均为同规模最快；响应长度压得最狠。

两边成立

有 KL 的组更「收」

E1 GRPO / E4 RLOO（及 E5 的 mse-KL）熵与梯度更稳；关 KL 的 E2/E3 更容易走极端（熵松或熵紧）。

两边成立

数学 RL ≠ Agent 增益

BFCL MULTI_TURN 普遍个位数到低十位数；换算法救不回来。tau-bench 有区分度但噪声大（±8pt）。

规模反转

Dr.GRPO 长度：2B 最长涨 → 4B 最短涨

2B 上 E3 长度涨幅最大；4B 上反而最小（5.3k→7.3k），且熵全场最低最紧。同一算法、不同规模行为可反号。

规模反转

DAPO 数学：2B 弱势 → 4B 峰值

2B offline aime25@150 仅 30%（五组偏低）；4B 峰值 aime24/25 都是 E2@80。小模型上「压长度」未必换来数学，大模型上可以。

2B 4B

训练 pass 区分度随规模下降

2B 末段 pass 算法间差明显；4B 挤在 88–91%。4B 必须看 offline，不能只看 train reward。

维度 2B（Qwen3.5-2B） 4B（Qwen3.5-4B）
训练画像 差异更大、算法排序更「散」；长度/耗时/熵分化清晰 Easy-Boxed 末段 pass 同处 88–91%；「训练曲线像、评测不像」
数学 offline aime25@150：E4 37.5% 领先，E2 仅 30% 峰值 E2@80 = aime24 80.4% / aime25 62.5%；定盘仍偏 E2
通识 MMLU 峰值 E3@100 = 82.4%；@150 偏 E4/E5 全程 90–92% 窄带；峰值 E3@120 = 92.5%
适合做什么 算法敏感度对照；扫超参便宜 冲 offline 数学峰值；必须扫中段 ckpt

2 · Param（共享超参与算法开关）

本轮「固定块」vs「算法可变开关」——结论主要来自开关差异，不是扫参网格

共享不变量（2B / 4B / MM 文本侧对齐）
非思考 · max_response_length=16384 · train_batch_size=32 · rollout.n=8 · lr=1e-6 · total_training_steps=150 · data.seed=1 · FSDP2。 赛道之间只改模型规模或数据模态，不改这套共享超参定义。
Param / 开关 谁开谁关 观察到的效应
KL loss 开：E1 / E4 / E5
关：E2 / E3		 开 KL → 熵更收、墙钟多一次 ref、曲线更稳。关 KL → 更快，但 4B DAPO 熵走松 + 偶发 grad 尖峰；Dr.GRPO 熵极紧。
组内 std 归一化 开：E1 GRPO
关：E3 Dr.GRPO		 关掉 std + 固定分母聚合 → 通识峰值常出（mmlu），长度行为随规模反转，必须盯曲线。
Overlong shaping 主要 E2 DAPO 两边都把响应压到最短；是吞吐与长度指纹的主开关。小模型上「短」未必换数学分。
Clip-Higher / Dynamic Sampling E2 DAPO 保探索 + 丢掉全对/全错组；与关 KL 叠加后 4B 数学峰值最强，也带来熵松风险。
Advantage 估计 组均值 / LOO / batch 白化 RLOO（E4）在 2B 定盘数学最好；REINFORCE++（E5）batch 白化 + mse-KL，通识友好、更新偏稳。
数据难度（Easy vs S3） 同算法换 train set Pass 尺度不可跨数据直接比。2B S3 offline 数学整体低于 Easy（aime25@150 ≈ 22–26%）。
  • 本轮没有做 lr / n / batch 网格。改 rollout.n、LR、开 thinking，排序可能整表重写——见边界节。
  • 墙钟排序由「要不要 ref」主导： DAPO < Dr.GRPO ≈ REINFORCE++ < RLOO / GRPO。要扫超参，先用 DAPO 省机时。
  • 选 ckpt 比微调单个标量有时更关键：多组中段峰、末段回落——部署应扫 offline 曲线，不要默认 step150。

3 · MM（多模态 · 图文配比）

固定 Qwen3.5-2B + GRPO + 共享超参，唯一自变量 = 训练数据图文占比（M0–M3）

这一轴回答的问题
① 视觉推理（Geo3K）随图文占比怎么涨；② 混入图文后，纯文本数学相对 M0(=E1) 被稀释多少。 算法、分辨率、底座均锁定——不与 E2–E5 交叉，避免归因混乱。详情 多模态训练。
组 图文占比 训练状态 当前结论
M0 0%（纯文本） 复用 E1@150 正式基线已齐。 Geo3K sample acc 57.3%（pass@8 83.7%）； MATH-500 86.4% · MMLU 78.3% · AIME24/25 35.4% / 32.5%。 文本端点 = 算法轴 E1，可直接对齐。
M1 100% Geo3K 150/150 满 light 探查：Geo3K @70→@100 = 13.6% → 14.8%（n=1 / 512 tok，不可与 M0 formal 横比绝对值）。 文本 light@70：MATH-500 23.6% / AIME25 6.7% / MMLU≈1% —— 纯图文对文本能力杀伤很大（口径弱，趋势可信）。
M2 50% 混合 150/150 满 训练曲线已同步（mixed reward 可按 source 拆分）；formal / light 离线评测待补——配比权衡曲线的关键中间点。
M3 20% 混合 150/150 满 训练曲线已同步（mixed overall；dump 无 modality tag）；formal / light 离线评测待补——配比权衡曲线的低图文端点。

已成立（弱）

100% 图文会严重伤文本

M1 light 文本探针断崖式下跌；若要保数学，不要直接上纯 Geo3K 长训，优先等 M2/M3 权衡点。

待闭合

视觉–文本 Pareto 还没画完

需要 M1–M3 同口径 formal（Geo3K n=8 + evalscope）才能定量回答「20% / 50% 值不值」。

与算法轴正交

MM 不进 E1–E5 排名

多模态线固定 GRPO，结论是数据配比，不是换算法。下一轮若交叉算法，需单独立项。

下一刀候选

配比结论出来后再动别的轴

视觉编码器冻/解冻、分辨率、底座（Qwen3-VL）——等 M2/M3 formal 有信号再开，避免组数爆炸。

4 · Algorithm（E1–E5）

每行：设定 → 2B 画像 → 4B 画像 → 跨规模一句话（文本 Easy-Boxed 主赛道）

算法 2B 结论 4B 结论 综合
E1 GRPO 稳健 baseline；pass ~43%→63%；mmlu@150≈80%；aime25@150≈30% pass ~80%→90%；长度涨幅大（5.1k→9.7k）；训练 aime24@150 回落需对照 offline 有 KL、可复现的对照锚点；很少抢峰值，也很少翻车。MM 的 M0 即本组。
E2 DAPO 最短最快（~21h）；熵偏高；offline aime25@150 仅 30%，本数据未换来数学优势 仍最快（~32.6h）；熵 0.26→0.42 走松 + 两次 grad 尖峰；offline aime24/25 峰值全场最高（80.4% / 62.5%） 吞吐优先首选；数学收益随规模出现——小模型别默认「短=强」
E3 Dr.GRPO 末段 train-pass 最高带；熵最紧；长度涨幅最大；mmlu 峰值 E3@100=82.4% 熵仍最紧（→0.048）；长度涨幅反而最小；mmlu 峰值 E3@120=92.5%；梯度最稳 追求紧策略 / 通识峰值的强候选；长度行为会随规模反转，必须盯曲线
E4 RLOO 起步最快；offline aime25@150 最高（37.5%）；mmlu@150≈78.6%；墙钟略慢（多一次 ref） 走势接近 E1；训练验证 aime24 单点最高（step125=0.833）后回落；墙钟次高 2B 上「定盘数学」最稳的一组；4B 上更像带 KL 的稳健变体
E5 REINFORCE++ offline mmlu@150 最高（81.9%）；aime25@150 第二（36.7%） pass 与众同带；aime25@150≈57.5%（第三）；mmlu 与 E1 并列高位；无 E2 式尖峰 通识友好、更新偏稳；数学峰值偶发但不如 E2(4B) / E4(2B) 清晰

数值口径：offline 为 evalscope（math n=8，mmlu n=2，non-thinking）；训练 pass = (reward_mean+1)/2。详见各赛道「评测结果」页。

训练动态（跨轴）

pass · 长度 · 熵 · 梯度 · 墙钟

  • Pass 尺度不可跨数据直接比。 Easy-Boxed 与 S3（polaris_stage3）pass 带不同；4B S3 约 30–70%，需单独读图。2B S3 五组已满 150；4B S3 仍在推进。
  • 长度是算法指纹，也会被规模改写。 DAPO 两边都压长度；Dr.GRPO 在 2B「写长」、在 4B「写短」。
  • 熵是风险仪表。 4B DAPO 全程走松是本轮最醒目的风险；2B/4B 的 Dr.GRPO 都把熵收得很紧。关 KL 时务必盯 entropy + grad_norm。
  • 墙钟排序稳定： DAPO < Dr.GRPO ≈ REINFORCE++ < RLOO / GRPO。要扫超参/多 seed，先用 DAPO 省机时。
  • MM 训练另看 Geo3K train acc 与按 source 拆开的 mixed reward；≠ offline Geo3K test。

Offline 评测（跨轴）

AIME · MATH-500 · MMLU · Agent · Geo3K

数学：峰值 checkpoint ≠ 末步；选 ckpt 比选算法有时更关键
2B Easy：aime24 峰值 E2/E4@80–100 = 42.5%；aime25 峰值 E5@130 = 38.3%，step150 最高 E4 37.5%。 4B Easy：aime24 峰值 E2@80 = 80.4%；aime25 峰值 E2@80 = 62.5%，step150 仍是 E2（59.6%）。 多组存在中段峰、末段回落——部署应扫 ckpt，不要默认 step150。
  • MMLU： 2B 峰值 E3@100 = 82.4%，定盘@150 偏 E4/E5；4B 全程 90–92% 窄带，峰值 E3@120 = 92.5%。通识上 Dr.GRPO / REINFORCE++ 更常出头。
  • S3 vs Easy（2B）： S3 offline 数学整体低于 Easy（aime25@150 约 22–26%）。Stage-3 数据更难，不能拿 Easy 的绝对分去比 S3。
  • Agent： 数学 RL 对 agent 几乎无增益——BFCL MULTI_TURN 仍是最弱环；tau n=40，排序只可作弱证据。
  • MM： M0 formal 已给出文本+Geo3K 双基线；M1 light 只可看趋势；M2/M3 formal 齐了才能谈配比 Pareto。
  • 训练验证 ≠ offline： 尤其 4B E1 训练 aime24@150 走低时，必须以 evalscope 为准再下结论。

怎么选（按目标 × 轴）

先锁定规模 / 模态 / 是否动超参，再选算法

Size · 要吞吐 / 扫参

优先 DAPO（E2）

两边都最快、长度最短。4B 上数学峰值也最好；2B 上数学偏弱，适合当「便宜探索」。

Size · 2B 定盘数学

优先 RLOO（E4）

offline aime25@150 最高；有 KL、曲线好读。代价是墙钟略慢。

Param · 要紧策略 / 通识

Dr.GRPO 或 REINFORCE++

关 std / 开 mse-KL 的两条路：E3 熵最紧、mmlu 峰值常在；E5 更新稳、2B mmlu@150 最高。

Param · 要稳健对照

保留 GRPO（E1）

组内 std + KL 的经典设定；作 ablation 锚点，也是 MM 的 M0 端点。

MM · 要视觉且保文本

别直接上 M1 纯图文

等 M2（50%）/ M3（20%）formal；现阶段证据显示 100% Geo3K 文本崩得快。

Algo · 要上线 ckpt

扫中段峰值，别只交 step150

4B E2@80、2B 多组@80–130 常优于末步。用 offline 曲线选点，再用少量 seed 复核。

跨轴 · 要 agent / 工具

别指望换 RL 算法

需换数据或加 agent 轨迹；本轮纯数学 RL 换 E1–E5 救不了 MULTI_TURN。

跨轴 · 下一轮实验

先闭合 MM formal，再开新轴

配比 Pareto → 再考虑冻视觉塔 / 分辨率 / 4B×MM。避免与算法网格同时炸开。

边界与缺口

结论适用范围 · 尚未闭合的实验

这些限制会直接改变「谁更好」的排序
单 seed · 固定超参 · 非思考 16K · 训练数据 polaris_easy_boxed（及 S3）· 未跑 PPO。 换数据难度、开 thinking、改 rollout.n / LR，排序可能变。
  • Size： 4B S3 尚未五组跑满；S3 上的算法排序暂以 Easy-Boxed + 已有 S3 曲线为限。
  • Param： 无 lr / batch / n 网格；「Param」节是开关效应，不是超参最优解。
  • MM： M1–M3 训练均已 150/150；formal 评测未齐；M1 light 不可与 M0 比绝对值。
  • Algo： PPO 未纳入——不能推出「critic-free 一定优于 PPO」。Agent 评测噪声大，不宜细排名次。
