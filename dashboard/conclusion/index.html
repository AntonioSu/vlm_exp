一句话总览

Easy-Boxed E1–E5 在 2B/4B 均已跑满 150 步；结论基于训练曲线 + evalscope offline

没有「全能冠军」——目标不同，赢家不同
2B：墙钟/长度看 DAPO(E2)；末段 train-pass / mmlu 峰值看 Dr.GRPO(E3)；定盘 aime25@150 看 RLOO(E4)；mmlu@150 看 REINFORCE++(E5)。 4B：数学 offline 峰值与定盘均偏向 DAPO(E2)（aime24/25）；mmlu 峰值偏 Dr.GRPO(E3)；DAPO 仍最快但熵走松、偶发梯度尖峰。 两规模共同：数学 RL 几乎不抬 agent（BFCL MULTI_TURN 仍是最弱环）；训练 pass 高 ≠ 必然赢 offline AIME。

Track · 2B

差异更大、算法排序更「散」

末段 train-pass 拉开明显；长度/耗时/熵分化清晰。offline aime25@150：E4 37.5% 领先，E2 仅 30%。适合做算法敏感度对照。

Track · 4B

训练 pass 挤成一团，评测拉开差距

Easy-Boxed 末段 pass 同处 88–91%；但 offline aime 峰值 E2@80 = 80.4% / 62.5%，显著高于其它组。规模放大后「训练曲线像、评测不像」。

跨规模规律

成立 vs 反转 —— 读完这节再下钻单赛道

两边成立

DAPO 永远最快、长度最短

无 ref 前向 + overlong shaping：2B 墙钟 ~21h、4B ~32.6h，均为同规模最快；响应长度压得最狠。

两边成立

有 KL 的组更「收」

E1 GRPO / E4 RLOO（及 E5 的 mse-KL）熵与梯度更稳；关 KL 的 E2/E3 更容易走极端（熵松或熵紧）。

两边成立

数学 RL ≠ Agent 增益

BFCL MULTI_TURN 普遍个位数到低十位数；换算法救不回来。tau-bench 有区分度但噪声大（±8pt）。

规模反转

Dr.GRPO 长度：2B 最长涨 → 4B 最短涨

2B 上 E3 长度涨幅最大；4B 上反而最小（5.3k→7.3k），且熵全场最低最紧。同一算法、不同规模行为可反号。

规模反转

DAPO 数学：2B 弱势 → 4B 峰值

2B offline aime25@150 仅 30%（五组偏低）；4B 峰值 aime24/25 都是 E2@80。小模型上「压长度」未必换来数学，大模型上可以。

2B 特有 4B 特有

训练 pass 区分度随规模下降

2B 末段 pass 算法间差明显；4B 挤在 88–91%。4B 必须看 offline，不能只看 train reward。

算法 2B 结论 4B 结论 综合

E4 RLOO 起步最快；offline aime25@150 最高（37.5%）；mmlu@150≈78.6%；墙钟略慢（多一次 ref） 走势接近 E1；训练验证 aime24 单点最高（step125=0.833）后回落；墙钟次高 2B 上「定盘数学」最稳的一组；4B 上更像带 KL 的稳健变体

数值口径：offline 为 evalscope（math n=8，mmlu n=2，non-thinking）；训练 pass = (reward_mean+1)/2。详见各赛道「评测结果」页。

训练动态结论

pass · 长度 · 熵 · 梯度 · 墙钟

  • Pass 尺度不可跨数据直接比。 Easy-Boxed 与 S3（polaris_stage3）pass 带不同；4B S3 约 30–70%，需单独读图。2B S3 五组已满 150；4B S3 仍在推进（E1/E2 满，E3 进行中）。
  • 长度是算法指纹。 DAPO 两边都压长度；Dr.GRPO 在 2B「写长」、在 4B「写短」——不要用单一规模的长度故事外推。
  • 熵是风险仪表。 4B DAPO 全程走松是本轮最醒目的风险；2B/4B 的 Dr.GRPO 都把熵收得很紧。关 KL 时务必盯 entropy + grad_norm。
  • 墙钟排序稳定： DAPO < Dr.GRPO ≈ REINFORCE++ < RLOO / GRPO（后两者多 ref 前向）。要扫超参/多 seed，先用 DAPO 省机时。
  • Rollout↔训练一致性在有 KL 的组更接近 1；偶发尖峰（如 4B E2 step43/59）未必立刻打崩 pass，但要对照后续 offline。

Offline 评测结论

AIME · MATH-500 · MMLU · Agent（BFCL / tau-bench）

数学：峰值 checkpoint ≠ 末步；选 ckpt 比选算法有时更关键
2B Easy：aime24 峰值 E2/E4@80–100 = 42.5%；aime25 峰值 E5@130 = 38.3%，step150 最高 E4 37.5%。 4B Easy：aime24 峰值 E2@80 = 80.4%；aime25 峰值 E2@80 = 62.5%，step150 仍是 E2（59.6%）。 多组存在中段峰、末段回落——部署应扫 ckpt，不要默认 step150。
  • MMLU： 2B 峰值 E3@100 = 82.4%，定盘@150 偏 E4/E5；4B 全程 90–92% 窄带，峰值 E3@120 = 92.5%。通识上 Dr.GRPO / REINFORCE++ 更常出头。
  • S3 vs Easy（2B）： S3 offline 数学整体低于 Easy（aime25@150 约 22–26%）。Stage-3 数据更难，不能拿 Easy 的绝对分去比 S3。
  • Agent： 4B 结论「数学 RL 对 agent 几乎无增益」在 2B S3 上同样成立——BFCL OVERALL 有区分度，MULTI_TURN 仍弱（2B E1@150 摸到 ~17% 仍是最弱环）。tau 每点仅 40 条，排序只可作弱证据。
  • 训练验证 ≠ offline： 尤其 4B E1 训练 aime24@150 走低时，必须以 evalscope 为准再下结论。

怎么选算法

按目标取舍，而不是追单一榜首

要吞吐 / 扫参

优先 DAPO（E2）

两边都最快、长度最短。4B 上数学峰值也最好；2B 上数学偏弱，适合当「便宜探索」而非最终交付。

要 2B 定盘数学

优先 RLOO（E4）

offline aime25@150 最高；有 KL、曲线好读。代价是墙钟略慢。

要紧策略 / 通识

看 Dr.GRPO（E3）或 REINFORCE++（E5）

E3：熵最紧、mmlu 峰值常在；盯长度是否按规模反转。E5：2B mmlu@150 最高，更新稳。

要稳健对照

保留 GRPO（E1）

组内 std + KL 的经典设定；作 ablation 锚点，而不是冲榜选手。

要 agent / 工具调用

别指望换 RL 算法

需换数据或加 agent 轨迹；本轮纯数学 RL 换 E1–E5 救不了 MULTI_TURN。

要上线 ckpt

扫中段峰值，别只交 step150

4B E2@80、2B 多组@80–130 常优于末步。用 offline 曲线选点，再用少量 seed 复核。

边界与缺口

结论适用范围 · 尚未闭合的实验

这些限制会直接改变「谁更好」的排序
单 seed · 固定超参 · 非思考 16K · 训练数据 polaris_easy_boxed（及 S3）· 未跑 PPO。换数据难度、开 thinking、改 rollout.n / LR，排序可能变。
  • 4B S3 尚未五组跑满；S3 上的算法排序暂以 Easy-Boxed + 已有 S3 曲线为限。
  • Agent 评测噪声大（tau n=40）；BFCL 有区分度但 MULTI_TURN 地板效应明显，不宜细排算法名次。
  • PPO 未纳入——不能从本轮推出「critic-free 一定优于 PPO」。
  • 多模态线固定 GRPO、只改图文占比，结论见 多模态训练，不并入本页算法排名。
