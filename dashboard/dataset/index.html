Polaris-Dataset-53K

公开过滤根集

在哪： HuggingFace · POLARIS-Project/Polaris-Dataset-53K； 项目页 ChenxinAn-fdu/POLARIS。

S1 · Hard

偏难档 · Qwen3-4B 校准后的第一阶段池 · ~30K

数据形态：29,946 道题；全表 data_source=aime_stage1、ability=math、reward_model.style=rule；无顶层 difficulty。题干统一追加 step-by-step + \boxed{}（部分题含 Asymptote 图）。

来源（三层，均可在网上追溯）

  1. 公开母集： DeepScaleR-Preview ~40K + AReaL-boba ~106K。
  2. → Polaris-53K：按模型 8-sample pass rate 去掉「过易」（典型 8/8 全对），拼成 mirrored-J；约 26K 来自 DeepScaleR、27K 来自 AReaL（ POLARIS blog · HF 53K）。
  3. → S1（~30K）：再对 Qwen3-4B 做一轮难度校准，从 53K 滤到约 30K，作为 4B 多阶段课程的 stage1 池（blog 原文：additional filtering pass → 30K sample dataset）。

与 53K 的关系：去掉 boxed 后缀后，S1 题干均可在 Polaris-53K 对齐——是 53K 的真子集 + prompt 改写。相对 53K 约丢掉 23.3K；越易档丢掉越多（用 53K 的 difficulty 回标）：

和 Easy-Boxed 的差别：两者都来自 HF 上的 Polaris-53K，但切片方向相反—— Easy-Boxed ≈ 偏易档（多为 5–7/8）+ boxed； S1 ≈ 对 4B 再滤后的偏难子集（0/8 约占 39%）+ boxed，并改标 data_source=aime_stage1。 去重后 S1 ∩ Easy-Boxed 仅约 3.8K。
