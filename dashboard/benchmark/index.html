Math

AIME24 / AIME25

美国数学邀请赛风格竞赛题，测整数答案解题正确率。常见报告 pass@1 或多次采样的 mean / pass@k。

Knowledge

MMLU

多学科选择题基准，覆盖人文、社科、STEM 等，测通识与学科知识。

Function Calling

BFCL-v3

测函数调用是否写对：解析调用结构，比对函数名与参数；含单轮 AST、该不该调、以及多轮工具使用。

Agent

tau-bench

测多轮对话中能否用领域 API 完成任务：用户模拟器交互，按最终环境/数据库状态判成功。

AIME

竞赛数学解题

测什么：中等难度竞赛数学（如 AIME 2024 / 2025），答案通常是 0–999 的整数。

输入：一道完整题目（文字，偶含公式）。

输出：模型给出最终数值答案（常约定用 \boxed{} 等格式便于抽取）。

验证：抽取答案后与标准答案比对是否相等。可用贪婪解码（mean@1），也可用温度采样多次再算 mean 或 pass@k；协议不同，分数不可直接对比。

样例

题

Find the number of positive integers \( n \le 2024 \) such that \( n \) is divisible by 3 or 5 but not both.

答

模型输出推理过程，并以整数形式给出最终答案：

\boxed{945}
判
抽取数字后与标准答案比对；相等 → 对。

MMLU

Massive Multitask Language Understanding

测什么：57 个学科左右的多选题，覆盖从初等到专业水平的通识与领域知识。

输入：题干 + 若干选项（常见 4 选 1）。

输出：模型选择的选项（或对应字母）。

验证：选项是否与标准答案一致，通常报告准确率（accuracy）。

样例

题

Which of the following is a noble gas?

  • ANitrogen
  • BOxygen
  • CArgon
  • DChlorine
答
CArgon
判
选项与标准答案一致 → 对。

BFCL-v3

Berkeley Function Calling Leaderboard

测什么：模型能否根据用户请求与函数 schema，正确发起函数调用（含并行、多选一、该不该调、多轮工具使用等）。

输入：用户查询 + 可用函数/工具描述；多轮子集还有对话历史与可执行环境。

输出：函数调用（prompt 模式写成文本；也可走模型原生 tool-calling）。

常见子集与判分

  • AST（simple / multiple / parallel…）：把输出解析成抽象语法树，比对函数名、必填参数、类型、取值是否落在标准答案允许集合里。一般不执行函数。
  • RELEVANCE：测「该不该调」——无关请求不应产生有效调用；相关请求应产生有效调用。
  • MULTI_TURN：多轮 sandbox（如文件系统）。生成过程中会执行工具；评分按轮检查环境状态与工具返回是否覆盖标准轨迹，不要求每一步调用字面完全一致。

汇总指标：常报告 OVERALL（如 non_live / live / multi_turn 等类别再平均），以及单独的 MULTI_TURN 类别分。

样例（AST / simple）

问

Find the area of a triangle with a base of 10 units and height of 5 units.

工具 
calculate_triangle_area(base, height, unit?)
答 
[calculate_triangle_area(base=10, height=5)]
判
解析 AST：函数名与参数（base=10, height=5）落在 GT 允许集合 → 对；不执行、不算面积数值。

tau-bench（τ-bench）

多轮工具 agent · 任务完成

测什么：在模拟客服场景中，agent 能否依据政策文档与领域 API，与用户多轮交互并完成任务（常见域：retail、airline）。

输入：任务说明、领域 wiki、可调用工具列表；用户侧通常由另一个 LLM 扮演（user simulator）。

输出：多轮工具调用 + 对用户的自然语言回复。

验证：任务结束时比对数据库（及必要口头输出）是否达到 gold 状态——成功则 reward/acc = 1，否则 0。看的是任务是否完成，不是单次调用的 AST 字面匹配。

样例（retail）

用户

Hi, I received order #W2378156 and I’d like to handle a couple of exchanges from it.

Agent

先按政策做身份认证，再查订单……

  • tool: find_user_id_by_name_zip(first_name="Yusuf", last_name="Rossi", zip="19122")
  • tool: get_order_details(order_id="#W2378156")
  • …（继续换货相关 API，并在改库前取得用户确认）
判
对话结束后，数据库状态与 gold 一致（及必要口头输出齐全）→ reward = 1。
