概览

E2 DAPO · 一页速览

E2 · DAPO —— 4B 上全场最快，但出现两次瞬时梯度尖峰

Clip-Higher + Dynamic Sampling + Overlong Reward Shaping，关闭 KL loss；墙钟最快（32h33m）。训练侧 pass 末段与其它组同带，但 entropy 全程走高是本轮最突出的风险信号。

  • 算法设定：DAPO 三件套：Clip-Higher、Dynamic Sampling、Overlong Reward Shaping；关闭 KL loss（无 ref 前向）。
  • 学习信号：pass 末段与其它组同处高位；entropy 0.256→0.417 全程走高——四组中唯一没有收敛趋势。
  • 稳定性：step43 grad_norm→0.96、step59→1.13（其余 0.1–0.3），梯度图上两个尖峰；需关注后期是否熵失控。
  • 耗时：均值 ~12.9 min/step（gen ≈56%，update_actor ≈34%）；总墙钟约 32.6h，四组最快。
  • 评测亮点：offline aime24 峰值 E2@80=80.4%；aime25 峰值 E2@80=62.5%，step150 仍最高（59.6%）。

耗时拆解

单步墙钟 · gen / update_actor / ref / old_log_prob 等 stage

展开 stage 释义 · gen / update_actor / ref / adv …
  • gen (rollout)：vLLM 采样生成响应，通常占一半以上时间；随响应变长而抬升。
  • update_actor：FSDP 上策略网络反向与参数更新（PPO/GRPO clip 目标）。
  • ref：参考模型前向算 logprob，供 KL loss；关闭 KL 的组（如 DAPO / Dr.GRPO）此项为 null/≈0。
  • old_log_prob：用更新前策略再算一遍 logprob，供重要性采样 ratio。
  • update_weights：把新权重同步回 rollout engine（vLLM），一般数秒。
  • adv：advantage 计算阶段墙钟（含 reward 整理 + compute_advantage），不是 advantage 数值本身；通常 <1s。
  • reward：打分/奖励函数本身的计时；多数配置下几乎可忽略（≈0）。
