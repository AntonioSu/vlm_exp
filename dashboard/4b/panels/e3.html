概览

E3 Dr.GRPO · 一页速览

E3 · Dr.GRPO —— 熵收得最紧、梯度最稳，但长度涨幅反而全场最小

不除以组内 std + loss_agg_mode=seq-mean-token-sum-norm，关闭 KL loss。本轮最值得关注的是「2B 上长度涨最多 → 4B 上长度涨最少」的规模反转。

  • 算法设定：Dr.GRPO：advantage 不除组内 std；loss_agg=seq-mean-token-sum-norm；关闭 KL loss。
  • 学习信号：entropy 0.081→0.048 全场最低最紧；响应长度只 5.3k→7.3k，涨幅四组最小（与 2B 结论相反）。
  • 稳定性：grad_norm 基线全场最低（0.03–0.23）；更新保守、曲线最稳。
  • 耗时：均值 ~12.5 min/step（gen ≈55%，update_actor ≈35%）；总墙钟约 31.2h。
  • 评测亮点：offline 三项全 step 已齐；mmlu 峰值 E3@120=92.47%；aime24@120=75.0%、@140=73.3%。训练验证 aime24 step125 曾摸到 0.800。

单步墙钟 · gen / update_actor / ref / old_log_prob 等 stage

展开 stage 释义 · gen / update_actor / ref / adv …
  • gen (rollout)：vLLM 采样生成响应，通常占一半以上时间；随响应变长而抬升。
  • update_actor：FSDP 上策略网络反向与参数更新（PPO/GRPO clip 目标）。
  • ref：参考模型前向算 logprob，供 KL loss；关闭 KL 的组（如 DAPO / Dr.GRPO）此项为 null/≈0。
  • old_log_prob：用更新前策略再算一遍 logprob，供重要性采样 ratio。
  • update_weights：把新权重同步回 rollout engine（vLLM），一般数秒。
  • adv：advantage 计算阶段墙钟（含 reward 整理 + compute_advantage），不是 advantage 数值本身；通常 <1s。
  • reward：打分/奖励函数本身的计时；多数配置下几乎可忽略（≈0）。
